SVG 快速拆分工具 v0.11.10

遇到問題可以試試舊版：點我(v0.11.9)

只會幫你拆物件，不會幫你處理雕刻、刪重複物件、結合路徑、召喚颱風、競選總統。

點擊或拖曳 SVG 檔案至此

【不重要】以防有人看不懂

一、支援檔案

  • 僅支援 SVG 檔案；一次處理一個檔案。
  • 不支援的功能會原地消失。。

二、操作方式

  1. 上傳 SVG 檔案（Inkscape原始檔也可）。
  2. 選取檔案後，工具會自動解析並拆分，不需要另外按開始。
  3. 確認顯示的物件數量及警告訊息，再點擊「下載 ZIP」。
  4. 解壓縮下載的 ZIP，即可取得依序命名為 1.svg、2.svg、3.svg……的檔案。若原檔有兩個以上的圖層，檔案會依圖層分放在 layer1、layer2……資料夾中（檔案編號仍連續）。

三、可能出現的警告

若物件含有 Tinkercad 可能無法正確處理的內容，工具會顯示警告：

偵測項目可能影響建議處理方式
文字文字可能無法可靠匯入。在 Inkscape 選取文字，使用「路徑 → 物件轉成路徑」。
漸層／Pattern顏色可能被簡化為單色。改用純色填色。
濾鏡濾鏡效果可能被忽略。移除濾鏡效果。
Mask遮罩效果可能無法保留。先在 Inkscape 將效果轉換成實際形狀。
Clip-path裁切效果可能無法保留。先在 Inkscape 將效果轉換成實際形狀。
點陣圖嵌入的點陣圖不受 Tinkercad 支援。改用向量圖形。

警告只提醒可能的相容性問題，不代表拆分失敗，也不會阻止下載。工具不會自動修改圖形；請依需求在 Inkscape 處理後重新匯出。

四、使用注意事項

  • 拆分後會保留原始畫布尺寸及物件位置，不會自動裁切或重新定位。
  • 每個輸出 SVG 包含一個拆分物件及原檔的共用資源。
  • 圖層資料夾依由下而上編號，layer1 為 Inkscape 圖層面板中最下方的圖層（空圖層不計）；Plain SVG 不保留圖層名稱，因此以編號命名。
  • 匯入 Tinkercad 時，物件可能被自動置中；多個檔案匯入後如未對齊，請在 Tinkercad 手動調整。
  • 建議首次使用時，先將輸出檔匯入 Tinkercad，確認尺寸、顏色及挖孔效果。
